# Visual direction and palette

Use this as a source of hypotheses, not a genre-to-template converter. The track's actual
arrangement, the supplied assets and the user's cultural frame outrank every suggestion here.

## Direction axes

A direction becomes specific when it answers five questions:

| Axis | Question | Useful contrast |
|---|---|---|
| Material | Is the world optical, tactile, digital, organic, architectural or typographic? | clean glass vs damaged tape; ink vs machined metal |
| Space | Is it flat, layered, enclosed, infinite, miniature or monumental? | flat poster vs deep corridor; intimate macro vs vast void |
| Geometry | Are forms soft, modular, fractured, repetitive, fluid or calligraphic? | strict grid vs uncontrolled growth |
| Time | Does motion breathe, drift, snap, accumulate, decay, stutter or travel? | slow morph vs impact frame; continuous gesture vs hard cut |
| Address | Does the video perform, narrate, illustrate lyrics, demonstrate a system or create a trance? | character focus vs anonymous procedural spectacle |

Choose one primary and at most one secondary answer per axis. "Cyberpunk" alone is not a
direction; "a rigid monochrome signal space that gradually grows organic faults" is.

## Translating musical families

These are starting points. Preserve the song's identity instead of collecting genre clichés.

| Musical character | Visual hypotheses | Avoid by default |
|---|---|---|
| House / disco | modular repetition, lit surfaces, spatial grooves, warm film or precise minimalism | changing the pattern before the loop has established itself |
| Techno | repeated geometry, industrial material, fog, deep perspective, restrained variation | maximum glitch from the first bar |
| Trance | long spatial ascent, radiance, gradual revelation, harmonic colour drift | constant cuts that erase the build |
| Drum & bass / jungle | fast directional gestures, fine detail, urban or organic syncopation | treating every subdivision as a full-frame flash |
| Dubstep / bass music | heavy scale changes, elastic material, negative space before impact | continuous maximum shake and brightness |
| Hard dance / breakcore | dense geometry, ruptured continuity, abrupt image grammar, playful or abrasive colour | undifferentiated noise with no intact reference |
| Glitch / IDM | systems under stress, topology, controlled discontinuity, mathematical transformation | arbitrary pixel damage unrelated to the arrangement |
| Chiptune | pixel structure, constrained palettes, game logic, crisp rhythmic state changes | mixing pixel art with unrelated glossy stock imagery |
| Synthwave / vaporwave | period-specific colour, media artifacts, nostalgic spatial icons, deliberate pacing | generic neon grid without a song-specific idea |
| Ambient / downtempo | slow fields, atmospheric depth, microscopic change, long holds | filling the frame merely to avoid stillness |
| Pop / electropop | clear graphic hooks, polished type, bold but controlled palette, performance / narrative focus | making the lyric secondary to procedural decoration |
| Dream pop / shoegaze | diffusion, soft focus, overexposed edges, layered atmosphere | sharp HUD decoration and hard techno geometry |
| Rock / punk / grunge | physical texture, performance, collage, coarse print or film, direct gesture | polishing away all material evidence |
| Post-rock / progressive | long-form spatial or narrative development, delayed payoff | cutting only by a fixed beat interval |
| Metal | monumental scale, dense detail, forceful contrast, ritual / architectural forms | confusing darkness with an unreadable frame |
| Hip-hop / trap | performance presence, sampled material, typography, spatial weight, selective impact | automatic luxury / street clichés without context |
| Lo-fi / R&B / soul | tactile media, warmth, restrained camera, close framing, rounded motion | frantic beat visualisation of a deliberately relaxed track |
| Jazz / funk | phrasing, ensemble-like motif interaction, swing, print / stage references | quantising every gesture until the performance feels mechanical |
| Classical / cinematic | motif development, composed depth, narrative light, architecture and landscape | forcing verse / chorus labels onto a different form |
| Folk / world traditions | supplied cultural references, natural material, landscape, craft and pattern research | inventing sacred / ethnic symbols as generic decoration |
| Experimental / noise | custom rules, material failure, non-narrative systems, intentional discomfort within safety limits | using randomness as a substitute for a concept |

For rhythm-game BGA, Vocaloid, fan works and game soundtracks, community and source context
matter as much as genre. Research the actual work when permitted. Do not invent characters,
lore, logos or symbols, and do not expose the user's instructions as fictional screen content.

## Palette by roles

Assign every colour a job before choosing hex values:

1. **Ground:** the largest area and the reference for perceived brightness.
2. **Primary:** the hero image or main ink.
3. **Text:** chosen against the ground and against the busiest background state.
4. **Accent:** one event colour, reserved enough that its appearance means something.
5. **Optional secondary:** a distinct material / depth / narrative state, not another random accent.

Useful structures:

| Structure | Behaviour | When it works |
|---|---|---|
| Monochrome + accent | neutral ground / image, one saturated event colour | systems, severe electronic music, typography with a strong hook |
| Duotone | two colours encode dark / light or two materials | print, signal, graphic footage, unified mixed media |
| Analogous + light | neighbouring hues with a pale readable highlight | organic, dream, atmospheric and flowing images |
| Dark ground + two lights | one dominant light hue and one contrasting event hue | spatial 3D, trance, bass, luminous geometry |
| Warm / cool state pair | one palette per emotional or narrative state | songs with a genuine section-level turn |
| Constrained retro palette | deliberately few, period-coherent colours | chiptune, print, tape, pixel and archival media |

Starting points, not presets:

- `ground #0B0D10 / primary #E8EDF2 / accent #FF4D3D` — monochrome signal with a hot event.
- `ground #080A12 / primary #7A5CFF / secondary #35E0D0 / text #F4F7FB` — nocturnal neon.
- `ground #1D1712 / primary #E7D7BE / accent #D7683C` — warm print / film.
- `ground #101711 / primary #C8D6B9 / accent #E6B85C` — restrained organic material.

Do not judge a palette as swatches. Render the actual generator, footage and text together;
glow, alpha and blending can turn a balanced palette into mud. Check both the quietest and
brightest sections. Change palette at a structural boundary only when the new state is meant
to persist or the rupture itself is the musical point.

## Motif development

A useful motif can survive at least three transformations:

- **scale:** microscopic detail becomes landscape, or the reverse;
- **state:** order accumulates faults, solid becomes fluid, separate elements connect;
- **view:** the same object is revealed by orbit, travel, inversion or typographic reframing.

Plan those transformations across the song. A motif that cannot change should be a support
texture, not the whole video. A final chorus commonly works by returning to the established
motif with one amplified dimension, not by introducing an unrelated generator.

## Contrast budget

At any instant, spend emphasis on one or two of these: scale, brightness, saturation, density,
speed, sharpness, cut frequency, typography. If all rise together throughout the song, there
is no headroom left for the actual payoff. Before the largest drop, deliberately withdraw one
or two so the return is visible as well as audible.
