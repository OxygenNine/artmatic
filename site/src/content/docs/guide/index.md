欢迎使用 Artmatic！这是一个免费、开源的 Web 原生剪辑软件，针对算法艺术、故障艺术、平面设计等方面进行了功能上的特化。

## 安装

### 安装桌面端（Windows）

在 [GitHub Release](https://github.com/OxygenNine/artmatic/releases) 下载适用于Windows的Artmatic便携包，解压后双击“artmatic.exe”即可。

### 安装WebUI

由于 Artmatic 的视频编解码能力依赖于 Chromium 的 ffmpeg，因此它实际上可以完全在浏览器内运行，不需要独立的 ffmpeg.exe。

## 视图

在新建工程后你将看到 Artmatic 的主视图，由**侧边栏**、**预览画面**、**检查器**、**顶栏**和**时间轴**组成。

**侧边栏**是一系列功能的集合，从上到下依次是：

- 关于应用
- 查看快捷键
- 保存
- 媒体池
- 管理工程
- 插件
- Agent 任务
- 导出
- 设置
- 试炼场
- 切换深色模式

**预览画面**用于实时预览你的工程。

**检查器**位于最右侧，用于调整时间轴上的片段提供的各种可调项。通用的属性包括片段起止时间、位置和大小、不透明度和合成模式等；特效和生成器片段将提供对应的各类参数，排版片段则提供通往排版编辑器的入口。

**顶栏**用于在不同工程选项卡之间切换。当工程位于排版编辑器或其它子界面时，将在工程名称左侧显示图标用于区分。

**时间轴**用于快速调整片段的位置和起止时间。
