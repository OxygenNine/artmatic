这份手册写给要改 Artmatic 源码的人。每篇对应一件能做成的事：把项目跑起来、加一个特效、加一个生成器、把它接到 Agent 上。

## 规则与手册的分工

每个目录有一份 `AGENTS.md`，写的是「动手前必须知道」的约束、不变量和会再咬人的坑。手册讲步骤，`AGENTS.md` 讲为什么，以及哪里坏了不会报错。两份冲突时以 `AGENTS.md` 为准。

根 `AGENTS.md` 的「硬约束」一节对任何改动都成立。改渲染相关的代码之前先读它，尤其是时间、随机、有状态模拟这三条。

## 三条最常踩的

**改动是加法，装配只有一处。** 特效只走 `effects/` 的两个文件加目录表，生成器只走 `algos/` 的定义加注册表，合成只走 `createRenderCore`，导出只走 `runExport`。在别处再写一遍，症状是「一个入口好、另一个入口不对」，且不报错。

**着色器是惰性编译的。** 语法错误在你点到那个特效之前不会出现。改完先跑试炼场的「全部编译」。

**失效大多是静默的。** 参数没派发、uniform 拼错、`visibleWhen` 指向不存在的键，都不会抛异常，只是画面不动。所以每加一个东西，都有一条对应的守卫测试，见[测试与回归](/dev/testing/)。
