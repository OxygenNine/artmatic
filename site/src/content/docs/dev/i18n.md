界面上的每一句中文都来自 `src/i18n/`，没有第三方库。改文案在大多数情况下只需要动一个文件。

## 入口叫 tr()

```ts
import { tr } from '../i18n/index.svelte';

tr('tl.importAudio');
tr('tl.clipCount', { n: 12 });
```

翻译函数叫 `tr` 不叫 `t`，因为 `t` 在这个项目里是**帧号**的专名。拿它当翻译函数，会在每个渲染函数里制造命名冲突。

`i18n/index.svelte.ts` 必须是 `.svelte.ts`：locale 是 `$state`，`tr()` 每次调用都读它，模板里任何一处 `tr()` 都会自动建立依赖。换成普通模块加订阅回调，症状是「加了新文案却忘了订阅那一处，界面静默停在旧语言」。

## key 的形状

扁平点分命名，按域拆文件只是为了好找。合并之后就是一张平表，所以 `keyof typeof zhCN` 直接就是 `MessageKey`，拼错的键在类型检查时就报错。

```
'fx.solarize'        → 特效显示名
'fx.solarize.pivot'  → 该特效的参数名
'fx.desc.solarize'   → 一句话说明
'algo.gameOfLife'    → 生成器显示名
'algo.desc.gameOfLife'
'tl.importAudio'
```

| 内容 | 文件 |
| --- | --- |
| 特效显示名与参数名（`fx.<id>`、`fx.<id>.<key>`） | `media.ts` |
| 特效说明与分类名（`fx.desc.*`、`fx.cat.*`、`fx.tag.*`） | `effects.ts` |
| 生成器显示名、参数名、说明（`algo.*`） | `media.ts` |
| 时间轴、检查器、面板文案 | 各自的域文件 |

加一个新域要改两处：`locales/zh-CN/` 下新建文件，然后在 `zh-CN/index.ts` 与 `tests/unit/i18n.test.ts` 的 `DOMAINS` 各登记一行。漏登记的表现是「文案写对了，但跨文件重名检测覆盖不到它」。

## 数据表只存 key

`effects/defs/*`、`algos/*`、`typography/*`、`ui/shortcuts.ts` 这些表都在**模块加载时求值一次**。里面写 `tr('…')` 会把值冻在导入那一刻的语言上，症状极具误导性：切语言之后，只有那几项不动。

所以字段名带 `Key` 后缀：

```ts
{ key: 'pivot', labelKey: 'fx.solarize.pivot', type: 'range', … }
```

后缀是刻意的。它让「这里存的是键，用之前必须过 `tr()`」写在类型里，改名会让所有使用点编译报错。

插件的名字与说明是运行期字符串，给不出编译期键，所以那些字段的类型是 `Label`。读取点必须走 `resolveLabel()` 或 `labelOf(label, tr)`，不能直接 `tr(x.labelKey)`。内置的一行都不用改，因为字符串天然满足这个联合类型。

## 什么不进语言表

参数名、保留字、generator id、`assetId`、`console.*` 的输出、纯数值格式化（`1920×1080`、`12 ms`）都不进。

判据是**用户有没有可能看到它**。含「词」的带数字文案要进：`{n} 帧` 里的「帧」需要翻译。

占位符只认 `{名字}`，缺参数时原样保留。禁止用模板字符串拼句子，翻译时无法重排语序；三元表达式里的两句话也要拆成两个 key。

## 中文不许出现在别处

`src/` 下除 `i18n/locales/` 之外的中日韩字面量会被 `tests/unit/i18n.test.ts` 拦下。这条守卫看着严厉，它挡住的是「顺手在组件里写死一句提示」。

有一种情况会撞上它：**画进画面里的文字**。比如方框跟踪的标签词库、字符画用的字符集。这些东西不是界面文案，但同样不能写在模块里。现有做法是放进语言表（`fx.boxTracker.words*`），运行时 split 一次。

这种值不要在模块加载时 `tr()`，会冻在那一刻的语言上。用的时候现取。

## 加完文案跑什么

```
pnpm exec vitest run tests/unit/i18n.test.ts
```

只改文案时跑这一条就够，不需要跑 E2E。这也是刻意留的：如果改一句中文要动组件代码，说明有断言绑在了渲染后的字符串上。

加参数或特效时，`tests/unit/algo-params.test.ts` 还会检查每个 `labelKey` 能解析出来。所以忘加 key 的表现是测试直接红，不会拖到界面上才发现。

## 加一门语言

复制 `locales/zh-CN/` 整个目录，在 `locales/index.ts` 登记一行，不改任何组件代码。键集必须与现有语言完全一致，单测会逐个比对。
